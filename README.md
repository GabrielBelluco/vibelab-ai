# VibeLab AI

Uma experiencia front-end interativa para gerar direcao visual de interfaces com IA.

O projeto nasce com tres pilares:

- um mascote interativo que reage ao estado da interface;
- uma area de prompt para transformar ideias em direcao visual;
- uma base preparada para evoluir com Rive, Framer Motion e API de IA.

## Stack

- React
- TypeScript
- Vite
- Framer Motion
- Rive
- Lucide Icons

## Rodando localmente

```bash
npm install
npm run dev
```
